PandaForce 是通过自然语言组织项目、运行会话、查看请求和交付成果的浏览器工作区。

PandaForce 0.1.5 支持多个 Harness Runtime，已集成 Codex 与 Grok Build。先选择 Harness Runtime，再选择其 Model 和 Reasoning Effort。当前轮完成后，可以在同一会话中切换 Harness；历史记录与工作区文件保留，相关 Context 随切换交接。应用登录与模型服务登录相互独立。[Harness 配置指南](harness-runtimes.md)说明账户与容器配置。

从[安装指南](installation.md)开始，使用已发布的 `hiforceai/panda-force:0.1.5`。查看[功能清单](features.md)了解本版功能、可选服务与当前限制。源码贡献和镜像定制请参阅[开发指南](building.md)。
