# 完整功能清单

本清单对应 PandaForce 0.1.10，请使用配套发行镜像与配置文件。截图内容为虚构演示数据。

[English](https://github.com/hiforce/panda-force-free/blob/main/panda-docs/docs/features.md) · [README](https://github.com/hiforce/panda-force-free/blob/main/README-zh.md) · [安装指南](https://github.com/hiforce/panda-force-free/blob/main/panda-docs/docs/installation.md)

多数工作台与文档能力为内置功能。AI 操作需要已配置的 Harness Runtime 及对应模型账户；邮件需要 SMTP；网站构建、截图和可选搜索需要相应服务。下文明确说明覆盖不完整或尚未实现的部分。

## 工作台与导航

- 在工作台统一进入会话、项目、创作、技能、发布和助理。
- 从自然语言输入开始工作，提交前可添加文件、图片并选择项目。
- 按状态、项目和工作目录搜索筛选会话，置顶常用项目。
- 通过拖动或键盘调整桌面侧栏宽度，保留导航、草稿和阅读宽度偏好。
- 使用适配桌面与手机的布局、移动抽屉、键盘导航、明暗外观和可选主题。
- 支持英文、简体中文、香港繁体中文和台湾繁体中文切换；用户及引擎内容保留原文。

## 可定制首页与小组件

- 使用内置创作、最近工作、项目和技能小组件定制首页。
- 添加或移除小组件、修改配置、调整布局尺寸与顺序，并保存工作台。
- 调整布局时保留创作草稿，并处理未保存变更与受支持的布局冲突。
- 使用声明能力并通过隔离框架运行的受支持小组件扩展，扩展内容不会自动获得宿主机任意访问权限。
- 使用提供的小组件 SDK 与构建输入开发兼容扩展；这与尚未完成的通用发布渠道 SDK 分开。

## AI 会话与编程

- 通过实例独立启动的 Codex app-server，或明确接入的宿主机共享服务开展工作。
- 从已配置引擎选择模型及其支持的推理设置；模型认证与 PandaForce 账号独立。
- 流式接收回复，查看引擎提供的推理摘要、工具活动、命令输出、文件变更和执行状态。
- 在会话中处理命令和文件操作审批，回答结构化问题。
- 排队发送消息、停止工作、恢复受支持会话、并行管理会话并查看用量。
- 分页加载历史消息；共享模式轮询会合并读取并复用未变化的分页，避免扫描整份会话日志。
- 连接的 Codex 引擎支持时可使用目标及 token 预算；额外自动续接受控，默认关闭。
- 引擎支持时使用原生命令或技能补全、粘贴附件和会话独立输入历史。
- 通过会话工具浏览文件与变更、打开终端或已连接浏览器面板，并查看子任务。
- 搜索会话工具，置顶或排序最多三个快捷入口，并在浏览器本地保存会话笔记和清单。
- 切换阅读宽度与专注模式，查看精确 token 用量，并在导航时保持待审批事项可见。

## 项目与工作文件

- 按项目 code 创建真实持久工作目录，项目内新会话默认使用该目录。
- 把已有会话关联到项目，同时保留其原始工作目录。
- 在项目中集中组织文档、创作资产、会话历史、内容来源和发布工作。
- 浏览允许访问的目录，预览文本、代码、图片及受支持文档，下载生成文件与附件。
- 在当前账号有权限的范围内使用集成终端和引擎工作目录设置。
- 管理员可把目录浏览限制在指定项目根目录，并配置持久工作区、文档和附件存储。

## 个人创作与可复用资产

- 在创作中心保存个人文档、图片、视频、可编辑 PPTX 幻灯片、网页及导入文件，与独立的项目副本分开。
- 直接新建空白文档，或结合所选技能和来源内容生成 AI 草稿。
- 查看持久创作任务的进度、问题、错误和真实产物链接，重新打开产物继续编辑。
- 把个人作品复制到所选项目，生成独立内容，编辑一份不会静默覆盖其他副本。
- 通过已配置的 Codex 原生图片能力生成真实图片，也可生成可编辑 PPTX、自包含 HTML 和无配音动态图文 MP4；能力不可用时明确报错，不用策划文档替代成品。
- 根据已授权保存的原件继续受支持的修改。视频由字幕和允许使用的图片合成，此渲染器不生成实拍片段、配音或音乐。PPTX 提供文字预览和可编辑原件下载，不是完整的浏览器 Office 编辑器。
- 从项目文档目录打开图片、视频、音频、PDF 和文本，查看隔离静态网页预览，并下载其他格式的原件。

## 文档组织与编辑

- 用树状结构组织文档，创建子文档、排序或移动节点、搜索目录并使用面包屑导航。
- 默认阅读，按需进入专注编辑；手机端使用独立的阅读与编辑布局。
- 编辑标题、强调、列表、链接、引用、图片、表格和代码块等富文本内容。
- 使用选区浮动格式栏、块操作、统一插入菜单和支持语言选择的代码块工具。
- 自动保存草稿、显示保存状态、保留本地恢复内容，并检测编辑冲突。
- 查看修订与检查点、恢复已保存内容，并使用配置好的项目文件及 Git 文档后端。
- 回收或恢复文档及子树，同时保持文档与附件的归属边界。
- 独立存储文档图片，保留历史引用，导入受支持来源中的附件。

## AI 编辑与语言版本

- 在同一篇文档上继续 AI 修改，无需生成无关联的替代文档。
- 分别发起校对、排版、改写、摘要和翻译操作。
- 选择处理范围，逐项审阅建议后再应用到原稿。
- 处理过程中保护原稿，提供任务进度、可理解的失败原因和重试入口。
- 关联多语言版本，在受支持的生成与审阅流程中复用项目来源内容。

## 技能与技能包

- 按分类、搜索、封面、发布者、版本和许可证浏览内置及已安装技能。
- 从受支持的 JSON、ZIP 或 GitHub 来源发现并选择安装技能，批准前检查来源和所需能力。
- 从一包多技能中选择安装项，明确授予能力，并独立启用或停用导出技能。
- 会话及创作选择器只显示当前可用技能；停用、删除、未启用、未授权能力或当前不支持的许可版本不会进入使用候选。
- 在技能管理和版本历史中仍可查看不可用版本，但不将其作为可用选项。
- 按明确顺序组合多个技能、配置参数，并在返回详情后保留选择。
- 审阅升级、切换受支持版本、回滚或卸载技能包；不会为界面翻译而改写已安装包内容。

## 模板、主题与扩展

- 通过统一模板界面管理当前支持的文档、幻灯片、网页与站点主题类型。
- 使用前查看模板元数据、来源、许可证、版本和封面预览。
- 导入或导出受支持的模板 JSON、ZIP 包，并从仓库发现兼容包。
- 通过已配置的构建与预览服务生成站点主题首页、文章页及移动预览，并缓存结果。
- 使用受支持的原生主题、幻灯片导入与扩展权限；通用第三方渠道插件 SDK 和技能交易市场尚未完成。

## 来源连接与内容导入

- 检查并接入受支持的 Markdown、Hexo、Docusaurus 既有内容，配置导入规则。
- 导入期间对连接原件保持只读，把选定内容及图片带入托管文档流程。
- 作为 AI 上下文使用前查看来源文件及出处。
- 使用已实现的本地、SFTP 和受支持账号连接；凭据与发布目标由管理员配置。

## 搜索与知识工作流

- 检索有权访问的项目文档与内容；后端支持时可选择关键词、语义或混合模式。
- 无需外部搜索服务即可起步，也可按部署选项配置 Elasticsearch 与向量搜索服务。
- 查看搜索与索引状态，重建受支持索引，并跟踪进度或错误。
- 对选定来源配置项目知识规则，生成带来源依据的草稿，并进行独立审阅。
- 跟踪持久知识任务，审阅结论与不确定项，保留来源版本，区分生成判断和原始事实。

## 网站构建与发布

- 为文档或来源空间关联多个网站目标，不改写已保存原稿。
- 通过独立配置的执行器构建受支持的 Hexo、Docusaurus 网站，查看进度、日志、制品和预览。
- 配置主题与内容映射，发布前检查受支持格式的转换结果及警告。
- 发布到配置好的本地目标，使用制品归属与原子更新控制；受支持的 SFTP 流程需要信任及指纹核验。
- 查看历史执行、取消受支持任务，并使用目标适配器提供的回滚和保留控制。
- 无需直接发布时，导出受支持的原稿、HTML、纯文本或素材包。

## 社交发布与人工交接

- 区分 X Post、由多个 Post 组成的 Thread，以及独立的 X Article 发布类型。
- 准备受支持的渠道版本与预览，审阅格式损失及不支持项，避免静默修改原稿。
- 配置应用并满足平台权限及账号资格后，才能使用已实现的 X OAuth、账号及发布流程；当前覆盖仍不完整。
- 明确展示回调、未知结果及人工交接状态；不支持的渠道可使用导出内容。
- 当前分支不包含完整的时区与夏令时自动调度恢复、通用渠道 SDK，以及微信公众号、头条的完整直接发布。

## 助理与外部任务自动化

参见[匿名商品发布案例](https://github.com/hiforce/panda-force-free/blob/main/panda-docs/i18n/zh-Hans/docusaurus-plugin-content-docs/current/bot-product-publishing.md)，了解助理配置、受限调用密钥及企业系统集成。

- 创建具有指令、名称、code、头像和人设的助理，并独立启停。
- 为外部调用方分配和撤销助理访问密钥，将助理会话与交互会话分开。
- 幂等接收外部任务并进入持久队列，查看排队、执行、复核、完成及错误状态。
- 由任务请求声明业务动作与回调接口，兼容已有任务调用方。
- 审阅 AI 判断及依据、提交人工回复，并重试失败的回调投递。
- 优先基于任务文本判断，必要时检查图片；必需图片读取失败时进入复核，不能无依据执行最终动作。
- 查看按时间排列的任务事件，筛选搜索队列，配置受支持的保留、模型及回调域名设置。

## 本地账号与邮件恢复

- 初始化管理员时设置用户名和密码，安装阶段不强制填写邮箱。
- 先配置 SMTP，再验证并绑定邮箱；SMTP 凭据由管理员管理。
- 通过邮箱邀请成员，由收件人自行设置密码，管理员不替成员设置密码。
- 管理账号角色及状态；普通成员使用已授权业务内容，宿主机终端、宿主机文件浏览及共享 Codex 会话仅向管理员开放。
- 使用六位邮件验证码找回密码，服务端强制 60 秒防重发，验证正确后进入新密码页面。
- 不存在、未激活或停用的账号不会收到恢复验证码；成功重设后旧密码及会话失效。
- 已移除旧的专用 IDaaS 登录；通用 OIDC、Google、Slack 登录及组织通讯录同步不属于当前本地账号实现。

## 存储、数据库与管理

- 将产品状态、引擎状态、工作目录和附件保存在可分别配置的路径或数据卷。
- 安装时为应用业务记录选择 SQLite 或外部 MySQL，在设置中检查所选数据库状态。
- 使用按模块注册的结构迁移、前置检查、备份及受控迁移切换流程；文件资产、引擎日志与业务数据库记录分开。
- 管理员可按文件类型选择新创作原件使用 S3 兼容存储，配置与静态 CDN 分开；原件仍需应用认证，已有文件保持原位置。回收站保留可恢复，彻底删除才排队清理确切对象版本，并保留持久重试。原件路由不迁移会话附件、引擎历史和渲染恢复缓存。
- 公开源码快照不包含部署凭据、已加密连接数据、应用日志和管理员运行配置。
- 按需配置搜索、预览、构建、附件存储与集群服务，普通安装不以 Kubernetes 为前提。

## 安装、构建与 CDN

- 使用 Docker、Compose 与 `hiforceai/panda-force:0.1.10` 安装；Rocky Linux 9 镜像包含 Codex CLI、Grok Build、ZCode CLI 及创作工具，文档镜像目标为 Linux amd64。
- 使用配套发行配置。源码贡献与定制构建见[开发指南](building.md)。
- 独立配置构建、预览执行器，按需使用文档、搜索和预览服务的 Compose 覆盖文件。
- 可覆盖镜像、仓库凭据和拉取策略，包括使用私有仓库，无需把凭据写进应用源码。
- 默认从应用本站加载静态资源；启用 CDN 构建时使用自己的 S3 兼容 bucket、前缀、区域、可选 endpoint、访问 URL 及独立凭据文件。
- CDN 模式覆盖入口包、共享 HTTP 模块和按需模块；API 与认证始终保留在应用本站。
- 应用打包默认执行编译与打包检查，源码及受影响行为检查独立运行，不把构建当作全量回归证明。

## 安全边界与当前限制

- 共享宿主机执行引擎属于管理员信任边界，不是不受信任用户的代码沙箱；仅过滤路径不能隔离任意代码，也不能保护宿主机 API Key。
- 普通成员可使用已实现的授权内容工作流；每人独立沙箱中无限制编程、并由模型网关隐藏企业密钥的模式尚未实现。
- 企业供应商配置、成员配额、沙箱自动创建、委派访问密钥及按量计费仍处于设计阶段，不是已交付功能。
- 模型服务商、网络和外部平台限制仍然适用；可选连接需要部署者自己的账号、凭据和服务。
- MIT 许可允许商业使用；托管、模型、存储及平台费用另计；项目尽力维护，不提供 SLA。
