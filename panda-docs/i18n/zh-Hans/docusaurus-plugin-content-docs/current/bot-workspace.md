# 和熊猫聊天，也让它定时帮你做事

点击 **助理**，可以创建、编辑 Bot、查看汇总并进入任务管理。首页采用紧凑列表；已创建的 Bot 会以头像和名字显示在左侧“助理”下面，点击即可进入这个 Bot 的持续对话。

每个 Bot 只有一个人机对话。后台任务使用独立上下文，不会成为聊天消息。**清空对话**会删除全部人机消息、重置对话上下文并阻止执行中的旧回复重新出现。Bot 人格、任务、频道及已保存作品会保留。引擎历史清理尚未完成时，页面会显示清理状态和重试入口；新的回复不能复用旧历史。

普通会话的“会话信息”面板默认关闭，需要时点击顶部按钮展开。

## 场景：让研究熊猫每天整理新知识

1. 创建一个好奇、严谨的研究 Bot，打开 **外部集成 → 添加集成**。
2. 选择 **RSS / Atom**，填写订阅地址，要求“总结新观点，附上来源，区分事实和推测”。
3. 设置至少五分钟的执行间隔，或每天的时间与时区。
4. 保留私有内置频道，默认保存 30 天，可设为 1–365 天。
5. 保存后先 **预览来源**。预览只读取信息，不推进采集、不创建模型任务，也不投递消息。点击 **立即执行**，确认后才会按已保存的投递设置处理。

排程持久化保存在数据库中，应用重启和多个数据库节点不会各自重复启动同一时段。错过的排程会合并，不会集中补发。每条执行记录区分采集、Bot 处理和投递阶段；模型需要人工处理时，可以进入这个 Bot 的 **任务管理** 查看和恢复。取消集成执行可阻止后续处理；已经开始的外部发送仍可能完成，页面会保留真实回执。

采集有大小和数量限制。RSS 最多读取 1 MB、前 100 条，请为大型来源使用更聚焦的订阅。邮箱每次最多分页读取 100 个候选消息，并保存后续分页位置。预览会提示是否受限。RSS 按条目身份和内容去重，邮件按不可变消息 ID 去重。

## 配置连接，一次保存，多处复用

连接属于当前登录用户，可供该用户的多个 Bot 使用。凭据在服务器端加密保存，浏览器不会收到原始密钥。保存后先点击 **测试连接**，再启用对应集成。编辑时，所有凭据字段留空即可保留现有凭据；更换凭据后需重新验证目标账号。

- **Slack**：创建 Slack 应用，授予 Bot `chat:write` 权限，安装到目标工作区，并邀请 Bot 加入目标频道。在连接管理中填写 Bot Token、测试连接，再在集成的高级选项中选择连接与频道 ID。应用不会自动创建或修改 Slack 频道。
- **Gmail**：在 Google Cloud 项目中启用 Gmail API，创建 OAuth 客户端，让目标邮箱授权离线访问，以及 `https://www.googleapis.com/auth/gmail.readonly`、`https://www.googleapis.com/auth/gmail.send` 两个范围。填入客户端 ID、客户端密钥和刷新令牌，再验证邮箱。服务商授权及可能需要的 Google 应用审核仍由管理员完成。

不再使用的连接可以停用。API 仅允许删除已停用、且没有集成与保留投递记录引用的连接。请将加密密钥和数据库一起备份。Docker/Compose 将密钥保存在应用状态卷的 `config/bot-connection-key`，管理员也可通过绝对路径环境变量 `PANDA_FORCE_BOT_CONNECTION_KEY_FILE` 指定密钥文件。已有加密连接时丢失密钥，应用会报错，不会悄悄生成替代密钥。

## 邮件默认生成草稿，发送由你决定

邮箱集成只读取配置后新进入收件箱的邮件，不删除原邮件，也不下载附件。默认生成私有回复草稿；点击 **确认并发送回复**，核对固定的原发件人并编辑正文，再确认发送。Bot 不能自行更换收件人或邮箱；其他 Bot 或任务内容不能替代已保存的邮件来源。

自动回复是可选设置。启用或变更策略需要明确勾选授权，填写精确发件人白名单，并设置每个邮箱每天的 UTC 限额（1–50）。内容被截断、邮件列表或自动邮件、自己发给自己的邮件、无人回复地址、证据不足及无效模型结果，不会直接触发自动回复。共享的来源保留记录可避免多个集成对同一邮件重复回复；被拒绝或结果不确定的发送会保守占用已预留的限额。

应用在发起网络发送前持久化投递记录。超时、断连或服务商响应不明确，会显示 **发送结果待确认**，不会自动重发。Gmail 可点击 **核对已发送邮件**，按确定的 Message-ID 查询；没有查到不代表一定发送失败。Slack 的不确定结果需要到所选频道核实。只有明确遭拒的投递才提供重试。旧回执需要处理时，后续采集和模型工作仍可继续。

频道对用户和 Bot 隔离。到期内容会从读取结果中消失，并由持久清理流程移除保留的采集正文、频道结果和投递明细。缩短保留期会应用于已有内容；延长时间不能恢复已删除数据。仅含哈希和记录 ID 的去重标记可保留最长 365 天，避免重复回复；每日计数保留两天。已保存作品、普通任务、引擎历史与服务商原件使用各自的保留策略。这里的保留设置不会删除已经发送到 Slack 或 Gmail 的消息。

## API 集成

[英文接口参考](https://github.com/hiforce/panda-force-free/blob/develop/panda-docs/docs/bot-workspace.md#application-management-api)列出了 Bot 管理、持续对话、连接、集成、执行、频道和投递回执接口。这些接口需要应用登录会话、用户权限及同源写入验证，不能使用外部任务密钥读取对话或凭据。

发送消息、清空对话、启动集成及确认邮件均使用 UUID 请求 ID。网络响应丢失时，复用原请求 ID 查询或重试，避免创建第二次操作。更新连接和集成需使用返回的最新 `revision`；旧版本写入不会覆盖服务器上的新设置。

外部系统提交工作，请使用[Bot 任务 API 快速入门](bot-api-quickstart.md)，配置 Bot 范围的密钥、幂等请求，以及任务查询和取消。对话和后台任务仍保持独立。
