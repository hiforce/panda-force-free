Batch summary gadget

This example contains no simulated business records. Supply a provider that checks the current owner against your business system and returns a bounded summary. No PIM credentials belong in browser config.

bun build examples/gadget/batch-summary/frontend.ts --target browser --outfile /opt/panda/gadgets/batch-summary/frontend.js

Create an administrator-owned entry module:

import { readFile } from 'node:fs/promises';
import { createBatchSummary } from './server.js';
import { provider } from './your-business-provider.js';
export async function registerGadgets(registry) {
 const frontend = await readFile(new URL('./frontend.js', import.meta.url), 'utf8');
 registry.register(createBatchSummary(provider, frontend));
}

Build/copy the server adapter with the entry module and configure PANDA_FORCE_GADGET_MODULES as described in src/gadget/sdk/README.html. In a standalone package, replace repository-relative SDK imports with @hiforceai/panda-gadget-sdk/server or /frame. Bundle frontend dependencies; dynamic network imports are blocked by the sandbox.

canRead is executed on every data or action request. read must respect AbortSignal. open navigates to the existing Bot queue; adapt your registered action to an authorized application destination. All sample UI copy is supplied in four locales.
